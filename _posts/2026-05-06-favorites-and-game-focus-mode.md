*Game Focus Mode*

I've added a favorites feature and Game Focus Mode to [UnuOS](https://github.com/retronian/UnuOS).

[**UnuOS-20260504-0**](https://github.com/retronian/UnuOS/releases/tag/v20260504-0)

You can add a game to your favorites by pressing the Y button on the game's name.

And by pressing SELECT + Y, you can enter Game Focus Mode. In Game Focus Mode, only the games in your favorites are displayed — nothing else is shown.

You can exit Game Focus Mode by pressing SELECT + Y again.

[Game Focus Mode — UnuOS Wiki](https://github.com/retronian/UnuOS/wiki/Game-Focus-Mode)
